常用対数 ・ はじめて学ぶ人向け

図でわかる　$2^{n}$ の「桁数」と「最高位の数」

河合塾 2026年度 第2回 全国記述模試 数学 III型・大問1(3) ／ やさしい解説版

問

この問題

$\log_{10}2 = 0.301$ とする。

(i)　$2^{100}$ は何桁の整数か。

(ii)　$2^{n}$ は最高位の数が $4$ である $22$ 桁の整数である。正の整数 $n$ の値を求めよ。

最高位の数 ＝ いちばん上の位の数字。たとえば $47320$ の最高位の数は $4$。

答え（先に確認したい人だけ開く） (i) $31$ 桁　／　(ii) $n = 72$
1

$\log_{10}$ は「$10$ の何乗か」を表す数

$100$ は $10^{2}$、$1000$ は $10^{3}$。この「$2$」「$3$」が $\log_{10}$ の値です。 途中の数、たとえば $500$ は $10^{2}$ より大きく $10^{3}$ より小さいので、$\log_{10}$ の値は $2$ と $3$ の間の小数になります。

つまり $\log_{10}N$ は必ず「整数の部分」と「小数の部分」に分かれます。 そして、この $2$ つはまったく別のことを教えてくれます。

2

整数の部分 → 桁数

$3$ 桁の整数は $100$ から $999$ まで。つまり $10^{2} \leqq N < 10^{3}$ です。 このとき $\log_{10}N$ は $2$ 以上 $3$ 未満なので、整数の部分は $2$。 整数の部分に $1$ を足したものが桁数になります。

3

小数の部分 → 最高位の数

どんな数も「$1$ 以上 $10$ 未満の数 $a$」と「$10$ の累乗」の積の形に書けます。 このとき先頭の数字は $a$ の整数部分そのものです。

$N = a \times 10^{\,k-1}$（$1 \leqq a < 10$）の両辺の $\log_{10}$ をとると $\log_{10}N = (k-1) + \log_{10}a$。ここで $0 \leqq \log_{10}a < 1$ なので、 $\log_{10}a$ が小数の部分です。だから先頭の数字は小数の部分だけで決まります。

$4 \leqq a < 5$ を $\log_{10}$ の世界へ移すと、$\log_{10}4 = 0.602$、$\log_{10}5 = 0.699$ だから 小数の部分は $0.602$ 以上 $0.699$ 未満。$0$ から $1$ までが、先頭の数字ごとに $9$ 個の区間に分かれます。

この問題で使う道具（$3$ つだけ）

■ 桁数：$N$ が $k$ 桁 $\iff 10^{\,k-1} \leqq N < 10^{\,k}$
■ 最高位：$\log_{10}N$ の小数の部分を $\alpha$ とすると、最高位が $d$ $\iff \log_{10}d \leqq \alpha < \log_{10}(d+1)$
■ 指数を下ろす：$\log_{10}(a^{m}) = m\log_{10}a$

今回必要な値は $\log_{10}2 = 0.301$ だけから作れる。 $\log_{10}4 = 2\log_{10}2 = 0.602$、$\log_{10}5 = \log_{10}\dfrac{10}{2} = 1 - 0.301 = 0.699$。

4

(i)　$2^{100}$ は何桁か

方針
問われているのは桁数だけなので、必要なのは $\log_{10}(2^{100})$ の整数の部分だけです。 指数を下ろして $100\log_{10}2$ にすれば、$0.301$ を $100$ 倍するだけで求まります。

解答。　指数を下ろして計算すると

$$\log_{10}(2^{100})=100\log_{10}2,$$

$$100\cdot0.301=30.1.$$

整数の部分が $30$ だから $10^{30} \leqq 2^{100} < 10^{31}$、すなわち $2^{100}$ は $31$ 桁　$\cdots$（答）

5

(ii)　「$22$ 桁」「最高位 $4$」から $n$ を求める

方針
「$22$ 桁」は整数の部分の情報、「最高位が $4$」は小数の部分の情報です。 $\log_{10}(2^{n}) = 0.301n$ という式を $1$ 本用意すれば、どちらも $n$ についての不等式に書きかえられます。 あとは $2$ つを合わせて、その範囲に入る整数を拾うだけです。

解答。　$\log_{10}(2^{n}) = n\log_{10}2 = 0.301n$ とおく。

  1. 「$22$ 桁」を式にする。$22$ 桁 $\iff 10^{21} \leqq 2^{n} < 10^{22}$。 各辺の常用対数をとって $21 \leqq 0.301n < 22$。よって $0.301n$ の整数の部分は $21$ である。 小数の部分を $f$（$0 \leqq f < 1$）とおくと $0.301n = 21 + f$。
  2. 「最高位が $4$」を式にする。図5より $\log_{10}4 \leqq f < \log_{10}5$、すなわち $0.602 \leqq f < 0.699$。
  3. $2$ つを合わせる。$f = 0.301n - 21$ を代入して $0.602 \leqq 0.301n - 21 < 0.699$、 すなわち $21.602 \leqq 0.301n < 21.699$。

各辺を正の数 $0.301$ で割る（正の数で割るので不等号の向きは変わらない）。 $\dfrac{21.602}{0.301} = 71.76\cdots$、$\dfrac{21.699}{0.301} = 72.08\cdots$ より $71.76\cdots \leqq n < 72.08\cdots$。この範囲にある正の整数は $n = 72$ だけである。

よって $n = 72$　$\cdots$（答）

6

たしかめ と 手順のまとめ

$0.301 \cdot 72 = 21.672$。整数の部分が $21$ なので $21 + 1 = 22$ 桁。 小数の部分が $0.672$ で $0.602 \leqq 0.672 < 0.699$ なので最高位は $4$。どちらの条件も満たしている。

常用対数をとる→ 整数の部分と小数の部分に分ける→ 整数の部分 → 桁数 小数の部分 → 最高位→ $n$ の範囲を出す→ 範囲に入る整数を拾う
