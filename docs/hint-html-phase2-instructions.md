### 変換ルール（Phase 1 と同じ）

## 図（【IV】と【VI】のみ）

`.tex` の TikZ を SVG に移す。**座標は検証済みなので変更しない。**
`currentColor`、`class="solution-figure-svg"`、`viewBox` は Phase 1 の【I】の図に倣う。

**縦横比を必ず一致させること。**Phase 1 ではx方向32px/単位、y方向40px/単位になっており、
三角形の形が辺の長さと合っていなかった。**x方向とy方向で同じ倍率を使う。**

- **【IV】**：$y=(t-1)^2-4$ を $-1\leqq t\leqq4$ の範囲だけ描く。頂点 $(1,-4)$、
  端点 $(-1,0)$ は点を大きめにして $t=-1$ のラベルを付ける。$y=-4$ は破線。
  **$y=a$ の線は描かない**（$a$ は任意の実数で、1本に固定すると場合分けの1つしか表さない）。
  **$t$ 軸と重ねて $y=0$ の破線を引かない。**
- **【VI】**：単位円、$B=(0.8,0.6)$、$C=(-0.6,0.8)$（$B$ の $90^\circ$ 回転）、$A=(1,0)$。
  $\angle BOC$ は**弧とラベルではなく直角記号**で示す（`\bun{\pi}{2}` のラベルは辺と重なる）。
  $\theta$ の弧とラベルは $O$–$A$ 側に置く。

図は `solution` 側にだけ置く。**方針には図を出さない**（結果が漏れる）。

## 検証（1大問ごとに毎回）

```bash
node --check static/app.js
node scripts/check-exam.js
node scripts/check-solution-modal.js
```

ブラウザで、移した大問の**全小問**について確認する。**コード確認だけで完了としない。**

1. **方針に答えが出ていないこと。**小問ごとに1つずつ開いて確認する。**最重要。**
2. 「解答を隠す」を有効にしても方針は見られること
3. 解説モーダルが 問題 / 方針 / 解答 で、**答えが1回だけ**表示されること
4. KaTeXのエラーが0件であること（`document.querySelectorAll(".katex-error").length`）。
   **KaTeXは失敗しても例外を投げず、黙って崩れた表示になる。数式を目視すること。**
5. 未変換の生LaTeX（`\bun`・`\begin{align`・`\hspace`・`textgt`）が本文に漏れていないこと
6. 図：**SVGの点から辺の比を計算し、真値との誤差が1%以内**であること。
   ラベルが線分・軸・弧・他のラベルと重なっていないこと
7. **375px幅でモーダルが横スクロールしないこと**（`modalBody.scrollWidth <= clientWidth`）。
   長い数式は数式だけが横スクロールする（CSSで対応済み）。**モーダル全体がずれたら別の原因がある**
8. 日大など**未移行のデータセットが従来通り**であること
9. コンソールエラーが無いこと（`static/config.json` の404はローカル固有で無関係）

# Phase 2 修正記録（2026-08-19）

移植は30小問すべて完了し、機械的な検査（方針への答え・図の漏れ、KaTeXエラー、
答えの重複、375pxの横あふれ、図の縦横比と座標）はすべて通った。
内容面で2件を修正した。

## 1. 【II】(3) の誤字

方針が「**C**中心が分かっているので，」になっていた。`.tex` は「中心が分かっているので，」。
移植時に混入したもので、`C` を削除した。【III】(3) は同一参照なので同時に直る。

## 2. 【VII】(3) の方針が答えを明かしていた

**修正前**：「(1)の関係式と等差数列の和を組み合わせると，各項を順に決められます。
$a_{n+1}=2n-1$ が奇数であることから，0でないことも確認できます。」

(3) の答えは $a_n=2n-3$ であり、$a_{n+1}=2n-1$ は**添字をずらしただけの同じ式**なので、
解く前に方針を開くと答えが分かってしまう。

**修正後**：「…各項を順に決められます。各項が0でないことも同時に確認できます。」

**これは `.tex` の文面からの意図的な逸脱である。**`.tex` では方針と解答が同じ紙にあったため
問題にならなかったが、「解いている途中に見るヒント」という新しい用途で初めて表面化した。
**`.tex` に合わせて戻さないこと。**

## 修正しなかったもの（判断済み）

- **【V】の方針だけ常体**（他の6大問は敬体）。`.tex` の時点からの不統一で、移植は忠実。
  紙では大問ごとに別プリントだったので目立たなかったが、アプリでは同じUIに並ぶ。
  揃えるかどうかは未判断。**勝手に直さないこと。**
- **【VII】(1) の解答末尾**「初項は0ではないので $a_1$ で割ると，$a_2=1$ である。」が
  `answer` と一部重なる。これは「なぜ割れるか」という根拠を含む文であり、
  Phase 1 で削った純粋な結語とは性質が違う。削ると導出が消えるため残す。
