# 数学I・数学A 典型問題リサーチ

第4回以降の問題を作るときに参照する、数学I・数学Aの典型的な問題形式の整理。問題文・数値の転載ではなく、測る技能と問題形式の候補を残す。

## 使い方

- 問題を作る前に、各小問で測る技能をこの文書から1つ選ぶ。
- 同じ回の中で、同じ形式を重ねすぎない。
- Web・既存問題の出典と利用条件を記録する。反復練習を目的とする場合は、数値だけを変更した類題も利用できる。
- 実装時は `problem-authoring-principles.md` と `problem-source-map.md` を優先する。

## 数と式

数学Iの出題項目では、式の計算・因数分解、実数・根号を含む式の計算、1次不等式・絶対値を含む方程式と不等式が中心となる。

| 典型形式 | 測る力 | 少し難度を上げる条件 |
|---|---|---|
| 整式の整理・係数比較 | 展開後に同類項をまとめ、各係数を読む | 係数に文字を置き、条件から値を決める |
| 乗法公式による展開 | 平方・和と差・2項の積を使い分ける | 複数の式を展開してから整理する |
| 共通因数・公式による因数分解 | 式の形を見て因数分解の入口を選ぶ | 2文字の式、グループ分け、1文字に着目した整理 |
| たすき掛け型の因数分解 | 積と中項の係数を同時に満たす組を探す | 係数・符号を含む2文字の2次式 |
| 根号の簡単化・同類項計算 | 根号の中を簡単にし、同類根号をまとめる | 加減乗除を組み合わせる |
| 分母の有理化・共役 | 共役な式を用いて分母の根号を除く | 2つの分数をまとめて計算する |
| 絶対値 | 数直線上の距離として絶対値を解釈する | 絶対値が2か所ある式を境目で場合分けする |
| 1次不等式 | 不等式の性質を保って解を求める | 分数・二重不等式・連立不等式・整数解の個数 |
| 1次不等式の応用 | 条件を不等式に翻訳し、整数として判断する | 利益、費用、個数、範囲などの最小・最大を問う |

## 2次関数

2次関数では、グラフ、最大・最小、関数の決定、2次方程式・2次不等式との接続を区別して扱う。

| 典型形式 | 測る力 | 少し難度を上げる条件 |
|---|---|---|
| 軸・頂点・開き方 | 平方完成し、グラフの基本情報を読む | 一般形から平方完成する、切片も扱う |
| 平行移動 | 頂点形式と移動量を対応させる | 2つの放物線の移動量を比較する |
| 最大・最小（定義域なし） | 係数の符号と頂点から最大・最小を判定する | 最大／最小が存在しない側も判断する |
| 最大・最小（定義域あり） | 頂点と端点を比較する | 頂点が定義域の内外どちらかを判断する |
| 関数の決定 | 頂点・軸・通過点などから式を立てる | 頂点と1点、軸と2点、3点、切片と共有点を使う |
| x軸・直線との共有点 | 方程式とグラフを対応させる | 接する条件、共有点の個数、直線 (y=c) との共有点 |
| 2次不等式 | 放物線の上下関係から解の範囲を読む | (y\geq0) の整数解、パラメータによる場合分け |
| 日常事象への活用 | 二次関数で表された数量の変化を解釈する | 最大値・最小値を文脈に戻して判断する |

## 集合と論理

集合と命題は数学Iの範囲である。集合の記号だけを機械的に読む問題ではなく、条件と集合の包含関係、命題の真偽を対応させる形式を中心にする。

| 典型形式 | 測る力 | 少し難度を上げる条件 |
|---|---|---|
| 集合の表し方と演算 | 要素列挙・条件による表現、和集合・共通部分・補集合を読む | 数直線上の範囲と集合記号を相互に変換する |
| ベン図による関係整理 | 集合の包含・共通部分・補集合を視覚的に整理する | 2つの条件を同時に満たす／満たさない範囲を判定する |
| 命題の真偽 | 仮定を満たす具体例、反例を用いて真偽を判断する | 文字を含む命題で、反例を1つ挙げる |
| 逆・裏・対偶 | 命題から4種類を正確に作り、真偽の関係を理解する | 元の命題が偽のときも、対偶との同値を区別する |
| 必要条件・十分条件 | 条件の向きを集合の包含関係として判断する | 「必要十分」「どちらでもない」を含めて選ばせる |
| 対偶を用いる証明 | 直接示しにくい命題を、対偶へ言い換える | 整数の偶奇や平方数を題材に、証明の方針を問う |

注：要素の個数の公式 \(n(A\cup B)=n(A)+n(B)-n(A\cap B)\) は数学A「場合の数」の内容として扱う。集合と論理の小問へ混ぜる場合も、測る技能は数え上げとして記録する。

## 場合の数

場合の数は数学Aの範囲である。樹形図を描けば終わる問題だけでなく、順序を考えるか、重複があるか、直接数えるか余事象を用いるかを判断させる。

| 典型形式 | 測る力 | 少し難度を上げる条件 |
|---|---|---|
| 和の法則・積の法則 | 場合を漏れなく分け、段階ごとに数える | 条件によって選択肢の数が変わる設定にする |
| 数字の並べ方 | 桁数、先頭が0でないこと、重複の可否を扱う | 「特定の数字を含む」「偶数」「重複なし」を組み合わせる |
| 順列 | 順序のある選び方を \(nPr\) として表す | 隣り合う／隣り合わない、特定の人を固定する条件を入れる |
| 組合せ | 順序のない選び方を \(nCr\) として表す | 少なくとも1人、男女・種類ごとの人数条件を入れる |
| 重複を除く数え上げ | 重複した数え方を避ける、または包除原理を使う | 「AまたはB」を共通部分で調整する |
| 余事象 | 直接数えにくい場合を、全体から引く | 「少なくとも1つ」を「1つもない」の余事象にする |

30分の基礎チェックでは、複雑な場合分けを1問に重ねすぎない。条件は2つ程度までに留め、「順列か組合せか」「直接か余事象か」の選択を一つ明確に問う。

## 確率

確率も数学Aの範囲である。分母となる全事象を同様に確からしい場合として確定してから、事象の数え上げを行う構成にする。

| 典型形式 | 測る力 | 少し難度を上げる条件 |
|---|---|---|
| 基本確率 | 全事象と有利な事象を同じ基準で数える | サイコロ2個・カードなど、場合の数との接続を使う |
| 和事象・余事象 | 「AまたはB」「Aでない」を確率の性質で処理する | 共通部分を含む「AまたはB」や「少なくとも1回」を扱う |
| 独立な試行 | 各試行の確率を乗じる | 成功回数が指定された反復試行にする |
| 反復試行 | 成功・失敗の並びを組合せと確率で数える | ちょうどk回、少なくともk回を区別する |
| 条件付き確率 | 条件の下で全体を絞り、分母を更新する | 復元しない抽出、または表・樹形図から判断させる |
| 期待値（発展） | 結果と確率を重み付き平均として扱う | くじ・ゲームの損益を設定し、公平さを判断する |

期待値はJASSOの数学A相当の出題項目には含まれるが、学校の基礎チェックでは発展扱いとする。まずは基本確率、独立な試行、条件付き確率を優先する。

## 第3回との重複を避けるためのメモ

第3回では、二重根号、2か所の絶対値を含む不等式、2次関数の軸・最大最小・x軸との共有点を採用済みである。

第4回で優先して検討する形式：

- 数と式：係数比較、2文字の式の因数分解、共役な分母の有理化、分数を含む二重不等式、1次不等式の文章題
- 2次関数：平行移動、頂点と1点からの関数決定、定義域つき最大・最小、直線との共有点、接する条件
- 集合と論理：対偶、必要条件・十分条件、反例による真偽判定
- 場合の数：数字の並べ方、人数条件つきの組合せ、余事象を使う数え上げ

第4回の現行範囲は「場合の数」であり、確率は含めない。確率の節は、試験範囲を数学Aまで広げる回を作成する場合の候補である。
