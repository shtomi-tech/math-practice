# 数学I 典型問題リサーチ

第4回以降の問題を作るときに参照する、数学I「数と式」と「2次関数」の典型的な問題形式の整理。問題文・数値の転載ではなく、測る技能と問題形式の候補を残す。

## 使い方

- 問題を作る前に、各小問で測る技能をこの文書から1つ選ぶ。
- 同じ回の中で、同じ形式を重ねすぎない。
- 既存問題の数値だけを変えず、設定・式構造・問い方・条件のうち2項目以上を変える。
- 実装時は `problem-authoring-principles.md` と `problem-source-map.md` を優先する。

## 数と式

数学Iの出題項目では、式の計算・因数分解、実数・根号を含む式の計算、1次不等式・絶対値を含む方程式と不等式が中心となる。

| 典型形式 | 測る力 | 少し難度を上げる条件 |
|---|---|---|
| 整式の整理・係数比較 | 展開後に同類項をまとめ、各係数を読む | 係数に文字を置き、条件から値を決める |
| 乗法公式による展開 | 平方・和と差・2項の積を使い分ける | 複数の式を展開してから整理する |
| 共通因数・公式による因数分解 | 式の形を見て因数分解の入口を選ぶ | 2文字の式、グループ分け、1文字に着目した整理 |
| たすき掛け型の因数分解 | 積と中項の係数を同時に満たす組を探す | 係数・符号を含む2文字の2次式 |
| 根号の簡単化・同類項計算 | 根号の中を簡単にし、同類根号をまとめる | 加減乗除を組み合わせる |
| 分母の有理化・共役 | 共役な式を用いて分母の根号を除く | 2つの分数をまとめて計算する |
| 絶対値 | 数直線上の距離として絶対値を解釈する | 絶対値が2か所ある式を境目で場合分けする |
| 1次不等式 | 不等式の性質を保って解を求める | 分数・二重不等式・連立不等式・整数解の個数 |
| 1次不等式の応用 | 条件を不等式に翻訳し、整数として判断する | 利益、費用、個数、範囲などの最小・最大を問う |

## 2次関数

2次関数では、グラフ、最大・最小、関数の決定、2次方程式・2次不等式との接続を区別して扱う。

| 典型形式 | 測る力 | 少し難度を上げる条件 |
|---|---|---|
| 軸・頂点・開き方 | 平方完成し、グラフの基本情報を読む | 一般形から平方完成する、切片も扱う |
| 平行移動 | 頂点形式と移動量を対応させる | 2つの放物線の移動量を比較する |
| 最大・最小（定義域なし） | 係数の符号と頂点から最大・最小を判定する | 最大／最小が存在しない側も判断する |
| 最大・最小（定義域あり） | 頂点と端点を比較する | 頂点が定義域の内外どちらかを判断する |
| 関数の決定 | 頂点・軸・通過点などから式を立てる | 頂点と1点、軸と2点、3点、切片と共有点を使う |
| x軸・直線との共有点 | 方程式とグラフを対応させる | 接する条件、共有点の個数、直線 (y=c) との共有点 |
| 2次不等式 | 放物線の上下関係から解の範囲を読む | (y\geq0) の整数解、パラメータによる場合分け |
| 日常事象への活用 | 二次関数で表された数量の変化を解釈する | 最大値・最小値を文脈に戻して判断する |

## 第3回との重複を避けるためのメモ

第3回では、二重根号、2か所の絶対値を含む不等式、2次関数の軸・最大最小・x軸との共有点を採用済みである。

第4回で優先して検討する形式：

- 数と式：係数比較、2文字の式の因数分解、共役な分母の有理化、分数を含む二重不等式、1次不等式の文章題
- 2次関数：平行移動、頂点と1点からの関数決定、定義域つき最大・最小、直線との共有点、接する条件
