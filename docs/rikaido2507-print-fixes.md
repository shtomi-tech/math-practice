## 1. 【必須・数学的誤り】(5) の根拠が誤っている

**場所**：`I.tex` 解答 (5)、および方針 (5)

**現状**：解答に「また、$I$ は三角形 $ACD$ の内心でもある。」とある。
$I$ は三角形 $ACD$ の**辺 $AD$ 上**の点なので、その内心にはなり得ない（内心は内部の点）。

結論 $AI:ID=9:7$ は正しい。誤っているのは根拠だけ。

**修正**：解答の当該文と続く align\* を次に差し替える。

```latex
また、$D$ は辺 $BC$ 上にあるから $\angle ACD=\angle ACB$ であり、$CI$ は $\angle ACD$ の二等分線である。三角形 $ACD$ において、この二等分線は対辺 $AD$ と $I$ で交わるから、
\begin{align*}
AI:ID&=CA:CD\
&=3:\bun{7}{3}=9:7.
\end{align*}
```

方針 (5) の第2文を次に差し替える。

```latex
次に、$I$ は内心なので $C$ の角の二等分線上にもあります。$D$ が辺 $BC$ 上にあることから、この二等分線は三角形 $ACD$ における $\angle ACD$ の二等分線でもあり、対辺 $AD$ 上の点 $I$ に対して再び定理が使えます。
```

**修正**：$\sum$ だけの行を削り、部分分数分解の結果から直接書き下す。3行に収める。

```latex

&\quad+\left(\bun{1}{2n-3}-\bun{1}{2n-1}\right)\Bigr\}.
\end{align*}
```

3行目が段幅を超える場合は、2行目の `+\cdots` を3行目の先頭へ移し、4行に分ける。
